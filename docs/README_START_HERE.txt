AI DEVFEST - SMART ESCAPE - PARTICIPANT INPUT

Input file: building.json

This is the public sample dataset referenced by the Smart Escape shortened problem statement. Import it locally into your browser application. Use the published sample checks in Section 4.1 to verify your implementation.

It is a JSON object with building, nodes, edges and initial_state. Corridors are undirected, weights are positive integers, and initial_state arrays may be empty. Judges will test other files with the same schema; do not hard-code routes or locations.

Refer to the separate official mock-test problem PDF for complete functional requirements, commit requirements and deliverables.
