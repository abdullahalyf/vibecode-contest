# Smart Escape mock submission

## Project title

Smart Escape — Interactive Evacuation Route Simulator

## Description / abstract

Smart Escape is an educational evacuation route simulator in English and Bangla. Users import building JSON, choose a room or junction, and see the minimum-cost route to an open exit using corridor weights. Blocking locations or corridors and closing exits updates the route immediately. The app validates input, reports blocked starts and unavailable routes, and resets to the imported initial state. It supports keyboard controls, mobile map scrolling, PNG downloads and saved progress. Imported data, routing and saved progress stay in the browser.
